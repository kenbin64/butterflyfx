What the run did

The browser steps above are only part of it. The whole run, in order, with every result in the full report:

  • Created a throwaway database. A fresh PostgreSQL 16 in Docker, with the schema applied, and the demo app started against it.
  • Checked the connection. The host resolved, the port answered, a login ran SELECT 1, and the route was traced.
  • Tested the API. Six requests, including a missing record (404) and a customer with no email (refused).
  • Raced it. 25 create requests released at the same instant: all 25 succeeded, and exactly 25 rows appeared.
  • Filled every form. Good values first, then a wrong value in each field with the browser's own checks switched off. The server refused every one cleanly.
  • Attacked it. 18 SQL injection attempts through the forms and the API. No table was dropped, no row was deleted, and anything saved was stored as plain text.
  • Ran the workflows. Two multi-step macros, three times each with fresh Latin dummy data.
  • Cleaned up. 52 rows removed, both id sequences reset, the database matched its starting snapshot exactly, and then the database was deleted.

Run it yourself

You need Java 21, Maven, Docker and Google Chrome. Then one command builds everything and runs this same demo, with Chrome visible so you can watch it work. The HTML report opens at the end.

git clone https://github.com/kenbin64/testthispuppy.git
cd testthispuppy
demo.cmd        (Windows)
./demo.sh       (Mac and Linux)
