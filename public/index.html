Featured: a RAG service that refuses to guess

Most retrieval demos answer every question you ask. That is the problem, not the feature. citeline answers questions about US federal drinking water regulations, and when the corpus does not contain the answer it says so and stops.

citeline · python · fastapi · postgres + pgvector · hybrid retrieval

Retrieval augmented QA over 40 CFR Part 141, with an enforced citation contract

A regulation is a good test of a retrieval system because a plausible wrong answer is worse than no answer. Every response either carries a citation to the exact section it came from, or the service abstains. Three independent gates enforce that, and the last one re-checks the model's own output after the fact.

What I build

Three things, and they are the three places most AI projects fail on the way to production.

01 · retrieval

RAG that holds up

Structure aware chunking, dense plus lexical retrieval fused by rank, and a confidence gate that can decline. Grounded generation where citations are verified against the passages actually supplied, not trusted.

  • pgvector
  • hybrid + RRF
  • chunking
  • grounding

02 · pipelines

Ingestion you can schedule

Content hashed for idempotency, so a re-run over unchanged input writes nothing. Incremental, so only what changed is re-embedded. Quality gated at three stages, and every run recorded with a terminal status.

  • idempotent
  • incremental
  • data quality
  • observability

03 · evaluation

Numbers, not adjectives

Labelled golden sets, retrieval metrics (recall@k, MRR), and an explicit false answer rate measured against questions the corpus cannot answer. Thresholds chosen by sweeping the data, not by taste.

  • recall@k · MRR
  • abstention
  • threshold sweeps
  • CI gates

flagship · python · security

mcp-gateway

An audited Model Context Protocol server that gives a language model a closed set of read only tools over internal services. Arguments are validated rather than coerced, every call is logged including the refused ones, and a crash cannot leak internals to the model. Running on this site.
